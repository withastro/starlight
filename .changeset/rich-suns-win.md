Adds a new `askAi` plugin option to enable the DocSearch Ask AI feature using the ID of your [Algolia Agent Studio](https://docsearch.algolia.com/docs/agent-studio/getting-started/) agent.

See ["DocSearch configuration"](https://starlight.astro.build/guides/site-search/#docsearch-configuration) in the Starlight documentation for more details, including how to customize other Ask AI options.
